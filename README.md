# Token Town

A self-contained interactive showcase of AI labs as a living, shareable town.

## Run locally

```sh
cd /Users/rajatsingh/Documents/ChatGPT/token-town
python3 -m http.server 4173 --bind 127.0.0.1
```

Open [http://localhost:4173](http://localhost:4173).

## Interaction

- Arrow keys or Previous / Next: switch the highlighted lab
- Space: pause animated traffic
- `D`: day/night
- Share: use native sharing where available, otherwise copies a social-ready caption

The figures are deliberately illustrative demo data, so the app remains fast and works offline after the initial font load.
